# Roy Matus VR Cast

[English](README.en.md)

Приложение для LG webOS, которое принимает обычную трансляцию Meta Quest. Откройте приложение на телевизоре, затем выберите **Roy Matus VR Cast** в меню трансляции шлема.

**На Quest ничего устанавливать не нужно. USB, отладка шлема и работающий компьютер для просмотра не требуются.** Компьютер нужен для первоначальной установки на телевизор. Это экспериментальный выпуск 0.4.2, проверенный на LG 42LF653V-ZC (webOS 2.2, прошивка 04.06.75) и Quest 3S 9 ноября 2026 года. Совместимость с другими моделями не подтверждена.

## Что работает

- Видео и звук напрямую из Quest в LG, без промежуточного сервера на компьютере.
- Прозрачность/вид комнаты, если его передаёт штатная трансляция Quest.
- Звук в шлеме, на телевизоре или одновременно. Для звука **только на телевизоре** нужно вручную убавить громкость Quest; приложение не управляет громкостью шлема.
- Аппаратное воспроизведение H.264. На проверенной паре фактический поток — 1920×1080, около 30 кадров/с. Разрешение выше Full HD отклоняется.
- Обратная связь о доставке и потерях пакетов для регулирования битрейта отправителем. Автоматическое переключение разрешения не гарантируется.
- Пользователь подтвердил плавную картинку и задержку меньше секунды на домашней сети. Это наблюдение, а не гарантированная задержка для любой сети.
- Настройки в стиле старого LG webOS, управление стрелками, OK и кнопкой «Назад» пульта.

## Установка на телевизор

Приложение не опубликовано в LG Content Store. Устанавливаются два пакета: основное приложение и небольшой аппаратный плеер. В повседневном использовании открывайте **Roy Matus VR Cast**; плеер запускается автоматически.

### 1. Подготовьте LG

Установите **Developer Mode** из магазина LG, войдите в аккаунт LG Developer, включите **Dev Mode Status** и выполните предложенную перезагрузку. Снова откройте Developer Mode, включите **Key Server** и запишите IP телевизора. Телевизор и компьютер должны быть в одной домашней сети. [Официальная инструкция LG](https://webostv.developer.lge.com/develop/getting-started/developer-mode-app).

Это режим разработчика **телевизора**, а не шлема. Следите за **Remain Session** и нажимайте **EXTEND** до истечения сессии. После отключения Developer Mode LG удаляет установленные через него приложения. Для каждого просмотра открывать Developer Mode и Key Server не нужно.

### 2. Подготовьте установочный пакет

Скачайте ZIP из [Releases](https://github.com/RoyMatus/roy-matus-vr-cast/releases), распакуйте и откройте терминал в его папке. Установите [Node.js 22 LTS или новее](https://nodejs.org/).

```sh
node tools/prepare-install.cjs
npm install --global @webos-tools/cli@3.2.6
```

Первая команда скачивает опубликованный сторонний набор сертификатов совместимости, проверяет фиксированный SHA-256, соответствие ключей и подписи и создаёт `local-install/local.quest.receiver_0.4.2_all.ipk`. Интернет требуется только на этом этапе. **Не загружайте папку `local-install` в публичный репозиторий.** Пакет основного приложения из `dist` сам по себе не готов к подключению: используйте подготовленный пакет из `local-install`.

### 3. Подключите LG к установщику

```sh
ares-setup-device
```

Выберите `add`: имя `lg`, IP с экрана телевизора, порт `9922`, пользователь `prisoner`. Пароль SSH не задавайте. Затем:

```sh
ares-novacom --device lg --getkey
```

Введите **Passphrase** с экрана Developer Mode. Не публикуйте этот код или полученный ключ. Подробности команд: [webOS CLI](https://webostv.developer.lge.com/develop/tools/cli-dev-guide).

### 4. Установите и запустите

```sh
ares-install --device lg dist/local.quest.receiver.player_0.2.2_arm.ipk
ares-install --device lg local-install/local.quest.receiver_0.4.2_all.ipk
ares-launch --device lg local.quest.receiver
```

После установки компьютер можно выключить. Кабель USB между Quest и компьютером не нужен.

## Как пользоваться

1. Подключите Quest и LG к одной сети; предпочтительно LG по Ethernet, Quest по Wi-Fi 5 ГГц. Изоляция клиентов гостевой сети мешает обнаружению.
2. Откройте **Roy Matus VR Cast** на LG. В разделе **Звук** заранее выберите режим.
3. Наденьте Quest. Откройте **Камера → Трансляция / Транслировать**, выберите **Roy Matus VR Cast** и нажмите **Далее**. Названия пунктов могут отличаться между версиями Horizon OS.
4. Откройте игру. Изображение и выбранный звук появятся на LG. Одновременный звук может давать эхо из-за небольшой задержки телевизора.
5. Чтобы изменить настройки, завершите трансляцию в Quest или нажмите «Назад» на пульте LG. После выбора новых настроек начните трансляцию снова.

Режимы звука:

| Режим | Действие |
|---|---|
| В шлеме | Звук телевизора выключен, Quest продолжает звучать |
| На телевизоре | Звук телевизора включён; уменьшите громкость Quest вручную |
| В шлеме и на телевизоре | Включены оба; громкость каждого устройства регулируется отдельно |

## Если что-то не работает

- **Приёмника нет в списке:** откройте основное приложение LG, проверьте общую сеть и нажмите «Перезапустить». Закройте и снова откройте список трансляции Quest.
- **Выбрали телевизор, но видео не появилось:** завершите попытку в Quest, перезапустите приложение LG и попробуйте снова. Проверьте дату LG и наличие обоих установленных пакетов.
- **Рывки:** проверьте Wi-Fi Quest, расстояние до роутера и загрузку сети. Подтверждения кадров отправляются без ожидания таймера; неподтверждённые пакеты запрашиваются повторно.
- **Нет звука на LG:** выберите «На телевизоре» или «В шлеме и на телевизоре», проверьте громкость LG и звук в самой игре.
- **Нет комнаты в режиме прозрачности:** приложение показывает то, что передаёт Quest. Некоторые системные/защищённые экраны могут не входить в трансляцию.
- **Приложение исчезло:** проверьте срок Developer Mode; после его отключения потребуется повторная установка.

## Ограничения совместимости

Используется экспериментальный общий сертификат из [публичного набора Allcrafter1](https://github.com/Allcrafter1/cast-audio-receiver-bundles). Это не сертификат Google, выданный данному проекту, и не официальная поддержка Meta/LG. Обновление Quest или отзыв сертификата могут прекратить подключение. В наборе есть окна действия до декабря 2030 года; приёмник выбирает действующее окно и обновляет его в простое. Это не гарантия работы до 2030 года.

Приложение не записывает видео, звук или изображение комнаты на диск. Служебная статистика содержит счётчики и сведения о соединении. Используйте приёмник в доверенной домашней сети; отдельного PIN для отправителя здесь нет. Автоматическое управление громкостью Quest и гарантированная нулевая задержка не поддерживаются.
